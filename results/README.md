# Results

This directory holds **selected** experiment reports and the record schema, not raw output.

- `schema/run-record.schema.json` describes one line of `runs.jsonl`.
- Raw runs go to `results/runs/` (git-ignored). Commit only curated `report.md` / `summary.csv`
  files together with the scenario file and the code version that produced them.

Status: **Pending — not yet measured.** No result files are included until the experiments have been run.
